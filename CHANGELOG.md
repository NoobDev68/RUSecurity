# История изменений

## 1.0.0 — 2026-11-23

Первый публичный релиз RUSecurity.

- Сканер системы: процессы, автозагрузка, службы и драйверы, задачи, браузеры
  (профили, расширения, поиск, домашние страницы), hosts, брандмауэр, политики,
  точки восстановления, потоки NTFS, SigCheck, BCD, ассоциации файлов.
- Анализ отчётов детектором GenFix, список найденного с галочками и кнопкой
  «Рекомендовано».
- Свой фиксер: точка восстановления, бэкапы веток реестра,
  карантин файлов, журнал исправления.
- Откат исправлений целиком в разделе «Журнал».
- Карантин: восстановление, выборочное удаление, полная очистка.
- Проверка безопасности: аудит параметров Windows с описанием пользы и минусов,
  инструкциями для ручных проверок и автоматическим исправлением.
- Автоисправление настроек браузеров (поиск, домашняя страница, стартовые
  вкладки) для Chrome, Edge, Brave, Яндекс Браузера и Firefox.
- Удаление расширений Chromium: запись в профиле и папка расширения.
- Предложение перезагрузки после исправлений, которые её требуют.
- Русский и английский интерфейс, тёмная тема, портативная сборка одним exe.
