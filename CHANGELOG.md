# История изменений

## 1.1 — 2026-11-25

- Добавлен предпросмотр плана исправления: перед изменениями показывается
  dry-run-таблица действий.
- Появились поиск, фильтр по категориям, контекстное меню и исключения
  «больше не показывать» в результатах сканирования.
- Сканирование можно остановить кнопкой «Остановить».
- Добавлен экспорт сводки в Markdown и ZIP с отчётами и журналами для поддержки.
- Кнопка «Отблагодарить автора» и ссылка «Sponsor» ведут на CloudTips;
  в README добавлена ссылка «Я на Boosty».
- Добавлен режим «Тщательное сканирование»: COM-перехват, политики браузеров,
  ярлыки с рекламным URL, SvcHost/ServiceDll, корни дисков, все задачи
  планировщика и риск-оценка автозагрузки по подписи и пути.
- В тщательный режим добавлены процессы из пользовательских папок, BITS-задания,
  расширения оболочки/BHO, свежие исполняемые файлы, некавыченные пути служб,
  поисковые движки `Web Data` и Native Messaging. Чекбокс режима выделен красным.
- Добавлены проверки исключений Defender, прав расширений браузеров, сетевых
  соединений, DNS/прокси/WinHTTP, метаданных задач и риск-оценка Winlogon/
  Active Setup/AppInit/IFEO; COM проверяется и в HKLM, shell-расширения — в
  32-битной ветке.
- В тщательный режим добавлены устаревшие точки автозагрузки (`AppCertDlls`,
  `Winlogon\Notify`, `SilentProcessExit`, `BootExecute`, `ShellServiceObjectDelayLoad`,
  `SharedTaskScheduler`), пакеты LSA и поставщики учётных данных, проверка подписи
  и ACL папки для двоичных файлов служб, DLL вне системных каталогов, загруженные
  в процессы, входящие правила брандмауэра для программ из пользовательских папок,
  слушающие порты и маршруты по умолчанию через внешний шлюз. Строки результатов
  стали компактнее по высоте.
- В тщательный режим добавлены WMI-подписки (EventConsumer) и переопределённые
  пользователем переменные окружения (`ComSpec`, `windir`, `PATHEXT`, `PATH`).
- В проверку безопасности добавлены ограничение и журнал входящего NTLM,
  защита Defender от нежелательных программ (PUA) и правила ASR (защита LSASS,
  WMI-персистентность, уязвимые драйверы, обфусцированный код).
- Экран найденных элементов стал компактнее: поиск фиксированной ширины,
  кнопка «Исключения» — в одной строке с фильтрами, нижний блок с директивами
  и кнопками прижат к низу, поэтому таблица результатов стала выше.
- Кнопка «Рекомендовано» отмечает только те находки, в которых анализ уверен:
  BITS-задания, правила брандмауэра для пользовательских программ и
  пользовательские поисковые движки больше не выбираются автоматически.
- Проверка статических DNS больше не шумит: частные адреса (VPN, роутер,
  корпоративная сеть) не попадают в находки, показываются только публичные.
- «Рекомендовано» в проверке безопасности больше не снимает галочки с уже
  отмеченных необязательных проверок и считает знаменатель только по
  автоматически исправляемым (ручные проверки в него не входят).
- Уточнено, что «Очистить временные файлы» удаляет только содержимое папок
  Temp: в подсказке убрано упоминание кэшей, а перед исправлением показывается
  предупреждение о том, что именно очищается и что куки, пароли и входы в
  аккаунты не затрагиваются.
- «Рекомендовано» в сканировании больше не снимает директивы, включённые
  вручную, и точнее сообщает, сколько отмечено рекомендуемых.
- Удаление правила брандмауэра теперь перезапускает службу `mpssvc`, поэтому
  правило перестаёт действовать сразу, а не после перезагрузки.
- Откат стал выборочным: у выбранного исправления видно список объектов, и
  возвращаются только отмеченные. Если по прежнему пути уже лежит другой файл,
  он перемещается в папку бэкапа (`replaced`), а не теряется.
- Исключения поддерживают маски (`*реклама*`, `DNS: *`); маску можно добавить
  прямо в окне «Исключения».
- Поиск по найденному учитывает описание и строку исправления, а не только
  текст элемента.
- На экране результатов появились кнопки «Отметить всё» и «Снять всё»;
  удаление правила брандмауэра, BITS и прочие находки по-прежнему не
  отмечаются автоматически.
- Колонка «Раздел» в проверке безопасности подстраивается под содержимое.
- В тщательном сканировании три проверки (BITS, сетевые соединения, задачи)
  используют общий разбор PowerShell-вывода вместо копий.
- Добавлена опция «Очистить кэш и куки браузеров» (Chrome, Edge, Brave, Yandex,
  Firefox): очищает кэш и куки с предупреждением о выходе из аккаунтов.
- На странице «Откат исправлений» есть кнопка «Открыть папку» с бэкапами
  выбранного исправления.
- Откат исправлений вынесен в отдельный пункт меню (между «Карантином» и
  «Журналом»); в «Журнале» остались только текст лога, очистка и кнопка
  «Открыть папку журнала».
- Удалён неиспользуемый delta-скан (`core/delta.py`, флаги `--delta` и
  `--no-history`, снимки в `Reports/history`): интерфейс его не показывал.
- Вырезан мёртвый консольный код движка GenFix (настройка консоли, вывод и
  нумерация fixlist, проверка стороннего антивируса) и неиспользуемые хелперы
  фиксера.

## 1.0.0 — 2026-11-23

Первый публичный релиз RUSecurity.

- Сканер системы: процессы, автозагрузка, службы и драйверы, задачи, браузеры
  (профили, расширения, поиск, домашние страницы), hosts, брандмауэр, политики,
  точки восстановления, потоки NTFS, SigCheck, BCD, ассоциации файлов.
- Анализ отчётов детектором GenFix, список найденного с галочками и кнопкой
  «Рекомендовано».
- Свой фиксер: точка восстановления, бэкапы веток реестра,
  карантин файлов, журнал исправления.
- Откат исправлений целиком в разделе «Журнал».
- Карантин: восстановление, выборочное удаление, полная очистка.
- Проверка безопасности: аудит параметров Windows с описанием пользы и минусов,
  инструкциями для ручных проверок и автоматическим исправлением.
- Автоисправление настроек браузеров (поиск, домашняя страница, стартовые
  вкладки) для Chrome, Edge, Brave, Яндекс Браузера и Firefox.
- Удаление расширений Chromium: запись в профиле и папка расширения.
- Предложение перезагрузки после исправлений, которые её требуют.
- Русский и английский интерфейс: язык переключается на лету, без перезапуска.
- Тёмная тема, портативная сборка одним exe.
- Ссылка на донат в README и кнопка «Sponsor» на GitHub.
